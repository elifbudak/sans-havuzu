# 🎰 Şans Havuzu

Seçeneklerini gir, Enter'a bas ve şansını dene!

## 🚀 Nasıl Kullanılır?

1. Textarea'ya seçenekleri virgülle ayırarak yaz (`Elma, Armut, Muz`)
2. **Enter** tuşuna bas
3. Şans havuzu dönsün ve kazananı bulsun 🎉

## 🛠️ Kullanılan Teknolojiler

- HTML
- CSS
- JavaScript (Vanilla)

## 💡 Öğrenilenler

- DOM manipülasyonu
- Event listener kullanımı (`keyup`)
- `setInterval` / `setTimeout` ile animasyon
- Dinamik element oluşturma
